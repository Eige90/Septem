01 / Vermietung

Suchen. Prüfen. Buchen.

Fahrzeugkatalog

Suche nach Zeitraum, Standort, Marke, Modell oder Fahrzeugtyp.

Kundenkonto

Anmeldung und Registrierung für eigene Buchungen.

Verfügbarkeit & Preise

Die API prüft Buchungskonflikte und berechnet Angebote, Mietpreise und gegebenenfalls Transfergebühren.

Verwaltung

Separate Verwaltungsendpunkte mit Administrator-Authentifizierung und OpenAPI-Dokumentation.

02 / Architektur

Oberfläche und API arbeiten zusammen.

Browser  →  Next.js-Frontend  →  FastAPI  →  SQLite

Das Frontend startet lokal auf Port 3001, die API auf Port 8000. Katalog, Anmeldung und Buchungen werden über die API geladen. GitHub Pages allein führt diesen Server nicht aus.

03 / Lokal starten

Zwei Prozesse, eine Anwendung.

1. Projekt herunterladen

git clone https://github.com/Eige90/Septem.git
cd Septem

2. Backend starten · Python 3.11+

cd car-rental-api
python -m venv .venv
# Virtuelle Umgebung aktivieren
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload

3. Frontend in einem zweiten Terminal starten

cd Septem/car-rental-frontend
npm install
npm run dev

Die Anwendung ist anschließend unter http://localhost:3001 erreichbar; die API-Dokumentation unter http://127.0.0.1:8000/docs.
