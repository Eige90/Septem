# SEPTUM Deep Research Sources – Version 2

This build deliberately removes random-photo services and fictional demo vehicles from the seeded catalog.
Every seeded category contains at least three real-world entries and a curated image URL.

- Photo-based 360° reference: https://carshow360.net/en/porsche/911/gt3-rs-vii-8628
- Porsche official technical source (991.2 GT3 RS): https://newsroom.porsche.com/de/produkte/porsche-911-gt3-rs-saugmotor-automobilsalon-genf-weltpremiere-motorsport-weissach-aerodynamik-interieur-fahrwerk-technik-clubsport-14895.html

## Image policy

- Porsche hero/fleet photos: CarShow360/Samar links supplied by the user and referenced rather than copied into the repository.
- Remaining seeded images: curated Wikimedia Commons file paths. The individual file description pages carry the exact photographer and license.
- No LoremFlickr, generic random-image endpoint, landscape fallback, or category fallback is used for seeded vehicle cards.
